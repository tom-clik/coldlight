# About Research Co Ltd

This is a really simple template for publishing company research. The headers are "flow" headers and can be edited at the start of the HTML. To remove the date from the main header, just delete the element.

The table of contents is constructed manually. Each heading to appear in it has to be added to the list.

The main content has a slight indent. To not use this, remove or change the `layout-main` class.

The justification and line spacing on the main copy is actually added to every p tag within a section with classes of `scheme-justify` and `scheme-spaced` respectively. They are currently added to the body. Remove or add these classes to sections as required.
